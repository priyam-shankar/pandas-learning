# Pandas Learning

A hands-on repository documenting my journey of learning Pandas through Jupyter notebooks, code examples, and practical exercises.

## About

This repository contains my notes and code implementations while learning Pandas in Python. The goal is to understand how to work with structured datasets, perform data manipulation, clean raw data, and prepare datasets for analysis and machine learning.

The concepts are explored step by step, with practical examples using real-world style datasets.

## Topics Covered

### 1. Pandas Fundamentals
- Introduction to Pandas
- Series and DataFrames
- Creating DataFrames
- Reading CSV and JSON files
- Inspecting and understanding datasets

### 2. Data Selection and Exploration
- DataFrame properties and methods
- Indexing and selecting data (`loc` and `iloc`)
- Filtering data
- Exploratory Data Analysis (EDA)

### 3. Data Cleaning and Transformation
- Handling missing values
- Removing duplicate records
- String operations
- Data transformation
- Feature engineering
- Applying custom functions using `apply()`, `map()`, and `assign()`
- Renaming and sorting data
- Ranking and column reordering

### 4. Data Analysis
- Grouping and aggregation using `groupby()` and `agg()`
- Data reshaping using `melt()` and `pivot()`
- Merging and joining DataFrames
- Data concatenation

### 5. Data Visualization
- Histograms
- Scatter plots
- Basic visualization using Pandas

### 6. Working with Files
- Exporting DataFrames to CSV
- Exporting DataFrames to JSON

## Getting Started

Clone the repository:

```bash
git clone https://github.com/priyam-shankar/pandas-learning.git
```

Move into the project directory:

```bash
cd pandas-learning
```

Launch JupyterLab:

```bash
jupyter lab
```

Open `pandas_tutorial.ipynb` and run the notebook cells.

Make sure Python, Pandas, and JupyterLab are installed in your environment.
