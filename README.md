# Pandas Learning

A collection of Jupyter notebooks covering Pandas fundamentals, data manipulation, and practical exercises in Python.

## About

This repository contains my notes, code examples, and practice exercises while learning Pandas. The focus is on understanding how to work with structured data, inspect datasets, perform common data operations, and prepare data for analysis.

## Running the Notebooks

1. Clone the repository:

   ```bash
   git clone https://github.com/priyam-shankar/pandas-learning.git
   ```

2. Move into the project directory:

   ```bash
   cd pandas-learning
   ```

3. Open JupyterLab:

   ```bash
   jupyter lab
   ```

4. Open `pandas_tutorial.ipynb` and run the cells.

Make sure Python, JupyterLab, and Pandas are installed in your environment.
